백엔드가 필요해요

‘저장’이 필요하면

  • 여러 학생이 입력한 기록을 모을 때
  • 다른 기기에서도 같은 결과를 볼 때
  • 수업이 끝나도 기록이 남아야 할 때

💬 AI에게 요청할 때 이렇게 말해보세요

“학생들이 입력한 경기 결과가 저장되고, 모두의 화면에 순위가 보이게 해줘”

‘저장’, ‘여러 명’, ‘계속 남게’라는 말이 들어가면 백엔드가 필요하다는 신호예요

내 PC에서만 도는 웹앱

  • 내 PC 브라우저 서랍에만 저장
  • 파일을 보내도 데이터는 안 따라감
  • 내 PC가 꺼지면 끝
● 24시간 온라인
☁️

구글 서버에서 실행

  • 24시간 켜진 구글 서버가 대신 실행
  • 링크(URL) 하나로 누구나 접속
  • 내 컴퓨터로 돌리지 않고 배포 가능!
🔌 내 PC는 꺼졌지만 구글 서버 웹앱은 계속 동작!
